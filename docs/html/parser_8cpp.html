vector< Variable > parseRangesFile ( const string &  filename)

Parses a ranges input file and returns the list of variables with their live ranges.

Each non-comment line has the form "varName: p1, p2, ..., pN" where each program point is a line number optionally suffixed with '+' (definition/start) or '-' (last use/end). Multiple lines with the same variable name each define one live range; overlapping ranges of the same variable are merged into a single web by buildWebs(). Lines beginning with '#' are ignored.

Parameters
filenameName of the ranges file (relative to "../../datasets/ranges/").
Returns
Vector of Variable structs, each containing all parsed live ranges.
Exceptions
std::runtime_errorif the file cannot be opened or a line is malformed.

Registers parseRegistersFile ( const string &  filename)

Parses a registers input file and returns the allocation configuration.

The file must contain a "registers: N" line specifying the number of physical registers and an "algorithm: name[, param]" line specifying the algorithm. Lines beginning with '#' are ignored.

Parameters
