AllocationResult basicAllocation ( const Graph< int > &  graph,

)

Performs register allocation using the basic Chaitin simplification algorithm.

Runs in two phases:

  1. Simplification: repeatedly removes all nodes whose active degree is strictly less than numRegisters and pushes them onto a stack. If no such node exists, the highest-degree active node is selected as a spill candidate and pushed onto the stack optimistically (ties broken by smallest web id).
  2. Coloring: pops nodes from the stack and assigns each the lowest color not used by any already-colored neighbor. Optimistic spill candidates that cannot be colored (all numRegisters colors taken by neighbors) receive reg = -1 and are spilled to memory.

If any web is spilled, the pipeline marks all webs as spilled.

Parameters
graphInterference graph where each node is a web id.
websList of webs; the reg field of each web is updated in place.
numRegistersNumber of available physical registers (colors).
Returns
AllocationResult with register assignments and the count of registers used.
Note
Complexity: O(W * E), where W is the number of webs and E is the number of edges in the interference graph. Each of the W simplification steps scans all remaining active nodes and their adjacency lists to compute degrees.
