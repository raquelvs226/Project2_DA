Detailed Description

Configuration read from the registers input file.

Specifies the number of available physical registers, the allocation algorithm to run, and its optional numeric parameter.

Parameters
numRegistersNumber of physical registers available.
algorithmAllocation algorithm identifier ("basic", "spilling", "splitting", or "free").
paramOptional numeric parameter for the algorithm (e.g. max spills or max splits). Ignored when not applicable.
