vector< Web > buildWebs ( const vector< Variable > &  variables)

Builds the list of webs from the parsed variable live ranges.

For each variable, starts with each live range as its own group and repeatedly merges groups that share at least one program point until no further merges are possible. Each remaining group becomes one Web.

Variables are processed in alphabetical order so that web IDs are assigned deterministically. Within each variable, groups are sorted by their minimum program-point line before ID assignment, so IDs increase with earlier ranges.

Parameters
variablesList of variables, each with one or more live ranges.
Returns
Vector of Web structs representing the merged live webs, with contiguous IDs starting from 0.
Note
Complexity: O(V * R² * P²), where V is the number of variables, R is the maximum number of live ranges per variable, and P is the maximum number of program points per range.
