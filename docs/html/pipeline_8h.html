Runs the complete register allocation pipeline.

Orchestrates the workflow in the following order:

  1. Constructs webs from the variable live ranges with buildWebs().
  2. Dispatches to the algorithm specified in registers:
    • "basic": builds the interference graph and runs basicAllocation().
    • "spilling": runs spillingAllocation() with up to registers.param forced spills.
    • "splitting": runs splittingAllocation() with up to registers.param web splits.
    • "free": builds the interference graph and runs dsaturAllocation().
  3. If basic allocation reports any spill, all webs are assigned to memory and a warning is printed to stdout.
  4. Writes the result to outputFile with writeOutputFile().
Parameters
variablesList of variables with their parsed live ranges.
registersAllocation configuration (number of registers, algorithm, param).
outputFileName of the output file to write results to.
Exceptions
std::runtime_errorif an unknown algorithm name is specified.
