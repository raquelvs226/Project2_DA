Detailed Description

Represents a source-level variable and all of its live ranges.

A variable may be live in multiple, possibly non-overlapping, regions of the program. Each region is described by one LiveRange entry.

Parameters
nameUnique name of the variable as it appears in the source.
rangesList of live ranges associated with this variable.
