Writes the register allocation results to a text file.

The output file is written to "../../datasets/results/" and contains:

  1. A webs section listing all webs with their program points sorted in ascending order.
  2. A registers section mapping each web to its assigned register (r0..rN-1) or to memory (M) if it was spilled. If the allocation failed entirely, all webs are mapped to M and usedRegisters is 0.
  3. An optional spills section (only present for spilling allocation) listing the webs that were explicitly chosen for memory spilling.
  4. An optional splits section (only present for splitting allocation) listing each split performed, the two resulting sub-webs, and the save/restore line.
Parameters
outputFileName of the output file (relative to the results directory).
websList of all webs produced by the allocation (including split sub-webs).
resultAllocation result containing register assignments, spill info, and split log.
