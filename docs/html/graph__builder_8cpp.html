Graph< int > buildInterferenceGraph ( const vector< Web > &  webs)

Builds the undirected interference graph for a set of webs.

Creates one vertex per web and adds a bidirectional edge between every pair of webs that interfere according to websInterfere(). The resulting graph is used as the input to the graph-coloring register allocation algorithms.

Parameters
websList of webs to include as nodes in the graph.
Returns
Interference graph where nodes are web ids and edges denote conflicts.
Note
Complexity: O(W² * P²), where W is the number of webs and P is the maximum number of program points in any single web.

Checks whether two webs interfere with each other.

Two webs interfere if they share at least one program point that is not a definition-use boundary. A definition-use boundary occurs when one web starts (isStart) and the other ends (isEnd) at the same program point, meaning the new definition replaces the old value without them coexisting.

Parameters
aFirst web.
bSecond web.
Returns
true if the two webs interfere and cannot share a register.
Note
Complexity: O(|Pa| * |Pb|), where |Pa| and |Pb| are the number of program points in each web.
